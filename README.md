# Hashing-En-Salting

## Description

### run.py
Demonstrates the use of Argon2 encryption. With auto salt inside the hashing.
Used the same password to demonstrate the salting. The hashes are random with the same password.

### main.py 
Demonstrate the implementation of Argon2 encryption on a website with username and password.
Argon2 checks if the username and password are correct.


## How to start the program
### run.py
is a console-pyton program. Right click on the file then press Run.

### main.py
After installing the requirements you can run it right click on the file then select Run.
In console it will open a port click on it.
